About CleanLink

CleanLink is a demo web project created for the COMP3700 Web Computing course. Its goal is to simulate a platform where users can book car wash, laundry, and home cleaning services through a simple interface.

The project demonstrates front-end development, Bootstrap integration, JavaScript dynamic features, and cloud hosting using GitHub and AWS S3.
